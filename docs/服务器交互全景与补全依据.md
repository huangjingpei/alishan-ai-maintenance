## 非产品服务依赖

- 抖音网页和页面接口：自动化的实际目标，无法离线替代。
- `accountProxy.url`：由运行配置动态给出，具体协议需结合实际配置确认。
- 用户配置的 `webhookUrl`：属于客户自有服务，不应被本地产品服务无条件拦截。

## 生产运行配置密文

生产响应仍执行原流程：

- v2 密钥：`SHA-256("radar-runtime-v2|" + authToken + "|" + productSlug + "|" + productToken)`；
- v1 密钥：`SHA-256("radar-runtime-v1|" + authToken + "|" + productSlug + "|" + jwtSecret)`；
- 算法：AES-256-GCM；`iv`、`tag`、`enc` 均为 Base64；
- 解密结果仅保存在进程内存中。

本地开发明文分支必须同时满足 `HUOKE_LOCAL_DEV=1` 和 Electron 未打包状态。安装包不会进入该分支。

完整的本地响应示例、未实现接口建议契约和测试命令见《03_本地开发模式与接口契约.md》。
